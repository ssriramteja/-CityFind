# 🗺️ CityFind - US Address Lookup Chrome Extension

A lightweight Chrome extension that enables instant offline lookup of US addresses by city, state, or ZIP code. Perfect for researchers, data analysts, marketers, logistics professionals, and anyone who needs quick access to US address data.

![Version](https://img.shields.io/badge/version-1.0-blue)
![License](https://img.shields.io/badge/license-MIT-green)
![Chrome](https://img.shields.io/badge/chrome-extension-orange)

## ✨ Features

- 🔍 **Instant Search** - Search by city name, state code, or ZIP code
- 💾 **Offline Access** - Data stored locally using Chrome Storage API
- 📁 **Excel/CSV Support** - Upload `.xlsx`, `.xls`, or `.csv` files
- 🎯 **Smart Matching** - Flexible search with case-insensitive matching
- 🔄 **Persistent Storage** - Data persists across browser sessions
- 🎨 **Clean UI** - Modern, intuitive interface
- 🚀 **Fast Performance** - Handles thousands of addresses efficiently
